tools/golden/bytecode-widths-1.18.2.txt — the width evidence (D-235)
====================================================================

WHAT THIS IS. Extracts of `javap -p -c` over the REAL 1.18.2 server classes, taken on the
machine that has the jar by `tools/golden/ng_dump.js`, which writes the full disassembly of
eleven classes into its `ngwork/javap/`. Only the methods whose integer WIDTHS MC-Lite depends
on are kept here, because the point of the file is to be readable: a golden VALUE proves what
the game computes, and this proves WHY.

HOW TO READ IT. `imul` then `i2l` is a THIRTY-TWO-BIT multiply: it wraps, and is only widened to
long afterwards. `i2l` then `lmul` is a sixty-four-bit multiply. `isub`/`iadd`/`iflt` are int
arithmetic and can overflow on purpose. That distinction is the whole of D-229 and D-235.

PROVENANCE. server.jar SHA-1 c8f83c5655308435b3dcf03c06d9fe8740a77469 — the jar `vanillacheck`'s
golden world came off (D-199). Obfuscated names from Mojang's OFFICIAL server mappings, SHA-1
e562f588fea155d96291267465dc3323bfe1551b. Regeneration: tools/golden/README.md.
Obfuscated names: Mth=ajl  BitRandomSource=ctl  XoroshiroRandomSource=cux  WorldgenRandom=cuv
