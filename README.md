# MC-Lite

A browser Minecraft 1.18.2 that ships as ONE self-contained `dist/mclite.html`, opened by double-clicking, built for
low-end PCs. Worldgen and rendering may be cheap; everything else matches vanilla exactly (CLAUDE.md).

- **Play:** open `dist/mclite.html`.
- **Work on it:** `RUN.md` (sessions: `cloud session` / `loop session`).
- **For Dan:** `FOR-DAN.md`.
- **What is built and what is owed:** the phase issues (milestones, `tools/go.mjs status`) and `src/`; an open phase issue lists only what is still OWED. `docs/archive/ARCH.md` and `PLAN.md` are history and may be out of date.
